01 The Phantom Edge: Closed-Bar Backtests vs. Sub-Second Real-Time Feeds

The fatal mistake in retail backtesting lies in how standard engines log performance. If you run a trend-breakout system on 15-minute bars using TradingView or standard MT4 scripts, the engine reads four data points per candle: Open, High, Low, Close (OHLC).

When an entry triggers, your software waits for the trade to conclude, logging a clean +$1,200 win on your equity curve. What the retail report hides is that mid-way through that 4-hour trade, a sudden liquidity withdrawal pulled floating unrealized P&L down to -$5,200 for ninety seconds before price rebounded to hit your take-profit.

What Standard Backtests Report

"Strategy Passed: +12.4% Net Return"

Drawdown is calculated solely upon completed transactions. Intraday floating dips are ignored if the final closed candle exits positively.

Simulated DD: 3.2% (Calculated False Safety)
What Prop Firm Bridges Actually Execute

"Account Terminated: Daily Loss Cap Hit"

The prop firm's automated liquidation engine queries tick-level floating equity. At -$5,001 unrealized loss on a $100k account, your API access is revoked instantly.

Real Drawdown: 5.2% (Disqualification Triggered)

02 The Mathematical Formulations: Daily Loss Ceiling Mechanics

When constructing custom backtest scripts on BacktestLab Pro, you must mathematically program how different prop firms compute your liquid threshold floor ($L_{\text{floor}}$).

// Formulations for Daily Liquid Floor ($L_{\text{floor}}$)
Type A: Static Starting Balance Model (e.g., FTMO Classical)

Floor resets daily based strictly on balance at 00:00 server time:

L_floor = Balance_midnight - (AccountSize * MaxDailyLossPercent)
Type B: High-Water-Mark Floating Equity Model (e.g., Trailing Contracts)

Floor dynamically ratchets upward as open floating gains expand, locking in intraday highs:

L_floor = max(HighWaterMark_Equity) - (AccountSize * MaxTrailingPercent)

If your strategy holds winning trades that peak at +4% unrealized profit before trailing down to close at +1%, Type B firms treat that 3% retraction as active drawdown against your new floor. A backtester that does not calculate intra-trade profit retracement cannot accurately model this trailing ratchet trap.

03 Custom Backtest Implementation: Continuous MAE Tick Evaluator

Below is an operational quantitative execution block. Unlike basic script runners, this class tracks sub-minute ticks, updates trailing daily high-water marks, and logs exact intra-trade MAE deviations: 

/**
 * BacktestLab Pro - Prop Firm Drawdown Compliance Controller
 * Evaluates open position excursions and daily midnight threshold resets.
 */

class PropComplianceAuditor {
    constructor(accountSize = 100000, dailyCapPct = 0.05) {
        this.initialCapital = accountSize;
        this.dailyCapPct = dailyCapPct;
        this.currentBalance = accountSize;
        this.dayStartEquity = accountSize;
        this.lastDateRecorded = null;
        this.breachOccurred = false;
    }

    auditBarTick(timestamp, candleHigh, candleLow, openTrade) {
        if (this.breachOccurred) return { status: 'FAILED', code: 'ACCOUNT_TERMINATED' };

        const dateStr = new Date(timestamp).toISOString().split('T')[0];

        // 1. Midnight Server Threshold Reset Logic (17:00 EST / 22:00 UTC)
        if (this.lastDateRecorded !== dateStr) {
            this.lastDateRecorded = dateStr;
            this.dayStartEquity = this.currentBalance + (openTrade ? openTrade.currentUnrealizedPL : 0);
        }

        // 2. Calculate Maximum Adverse Excursion (MAE) inside bar interval
        let worstFloatingEquity = this.currentBalance;
        if (openTrade) {
            const adversePrice = openTrade.direction === 'LONG' ? candleLow : candleHigh;
            const worstFloatingPL = openTrade.calcPL(adversePrice);
            worstFloatingEquity = this.currentBalance + worstFloatingPL;
        }

        // 3. Audit against Daily Limit Floor
        const dailyFloor = this.dayStartEquity - (this.initialCapital * this.dailyCapPct);
        if (worstFloatingEquity <= dailyFloor) {
            this.breachOccurred = true;
            return {
                status: 'BREACH',
                time: timestamp,
                equityRecorded: worstFloatingEquity,
                liquidFloor: dailyFloor
            };
        }

        return { status: 'OK', bufferRemaining: worstFloatingEquity - dailyFloor };
    }
}

Deployment Blueprint

How to Execute Downloaded Codes for Real Trading

Step-by-step instructions to compile and deploy your algorithms on MetaTrader 5 terminals, VPS cloud servers, or automated Python broker APIs.

MetaTrader 5 (.mq5) Live Deployment

For FTMO, IC Markets, Pepperstone & all MT5 Brokers
  1. Open Data Folder: In your MT5 Terminal, click File > Open Data Folder.
  2. Place File: Navigate to MQL5 > Experts > Advisors and paste your downloaded .mq5 file.
  3. Compile in MetaEditor: Press F4 to open MetaEditor. Locate the file and click Compile (verify 0 errors, 0 warnings).
  4. Load Parameter Preset: In MT5, drag the EA onto the corresponding chart (e.g. XAUUSD M5). In the Inputs tab, click Load and select the provided .set preset file.
  5. Enable Trading: Enable "Allow Algo Trading" in the Common tab and click the master Algo Trading button on the MT5 toolbar.

Python (.py) API Integration

For Zerodha Kite, Angel One, Dhan & Crypto APIs
  1. Environment Setup: Install requirements in terminal: pip install pandas numpy MetaTrader5 kiteconnect.
  2. Configure Credentials: Open the .py file in VS Code or any editor. Enter your broker API key, secret token, and instrument symbol in the configuration block.
  3. Historical Warmup: The script automatically queries the last 20 bars via WebSocket or REST to calculate relative volume (RVOL) and session extremes.
  4. Event-Driven Execution: Run python main.py. The script executes order callbacks with built-in slippage tolerance and spread guards.
  5. Cloud Hosting: Run headless on an Ubuntu VPS or AWS EC2 instance with systemd daemon management for 24/7 uptime.
